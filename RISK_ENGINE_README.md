# Deterministic Risk Engine

This engine is a hard rule layer after Engine 3. It does not use an LLM and does not execute orders.

## Default controls

- 0.5% maximum account risk per candidate trade
- 2% daily-loss lockout
- Minimum 2:1 reward-to-risk
- Maximum 2% stop distance from entry
- Minimum 55% Engine 3 confidence
- Maximum two-hour decision age
- 30-minute high-impact-event lockout
- Good data quality required
- Engine 3 `wait` decisions are always rejected

## Run

```powershell
python run_risk_engine.py `
  --symbols "GC=F" "EURUSD=X" `
  --interval 1h `
  --account-balance 10000
```

For paper testing with Engine 3 `data_quality=limited`, add `--allow-limited-data`. This does not override `wait`, low confidence, staleness, invalid stops, daily loss limits, event lockouts, or reward-to-risk checks.

The default `value-per-price-unit` is 1. For a broker contract, set it to the amount of account-currency P&L generated by a one-unit position for a 1.0 price move.
